# CSE-Sem5-PrepHub 🚀

A comprehensive exam preparation hub and question bank portal designed for DBATU (Dr. Babasaheb Ambedkar Technological University) Computer Science & Engineering (CSE) 5th Semester students.

## 📚 Features

- **5th Sem Subject Portal (`index.html`)**: Interactive dashboard with subject cards, quick links, study guides, and progress tracking.
- **Machine Learning Question Bank (`ml.html`)**: Unit-wise breakdown of 51 long-answer questions compiled from university question papers (Winter 2022 to Summer 2024), priority frequency table, unit filtering, search, and local-storage progress tracking.
- **Database Management Systems (`DBMS_QuestionBank_DBATU.html`)**: Complete unit-wise PYQ analysis and question bank.
- **Semester 4 Archive (`sem4index.html`)**: Quick access to 4th semester resources.
- **Dark/Light Mode**: Full theme customization with persistent storage.
- **Responsive Design**: Optimized for desktop and mobile devices.

## 🌐 Deploy to GitHub Pages

To view this website live via GitHub Pages:
1. Go to repository **Settings** > **Pages**.
2. Under **Branch**, select `main` and `/ (root)`.
3. Click **Save**.
4. Your site will be live at `https://roshan-bhadane.github.io/CSE-Sem5-PrepHub/`!
